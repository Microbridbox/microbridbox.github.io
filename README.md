- assets/placeholder.png

How to publish:
1. Create a GitHub repo named `microbridbox.github.io` (public).
2. Upload the files from this package to the repository root.
3. In the repository Settings → Pages, ensure the source is the `main` branch and folder `/ (root)`.
4. Visit https://microbridbox.github.io after a minute to see the site live.

Replace the placeholder images and download links with your real assets and release links.
